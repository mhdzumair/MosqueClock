# Screen face scenario gallery

Each contact sheet contains the digital dashboard, analog dashboard, sub-hour Azan timer,
Friday bayan, full-screen countdown, and dua. Captures use a deterministic 1280×720 TV preview.

Regenerate the complete gallery with:

```bash
./scripts/generate_face_gallery.sh
```
