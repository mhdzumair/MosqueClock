# Clock face gallery

Browse the complete screen compositions for each face. Click an image to open the full-size sheet. English is shown below; expand the Tamil and Sinhala sections for localized versions.

## Screen coverage

The latest sheets for Horizon, Ufuq, Safaa, Noor, Sahar, Kaash, and Mihrab contain ten screens: digital, analog, azan under one hour, iqamah waiting, Friday bayan, azan countdown, dua, next-day Fajr, iqamah countdown, and Friday-night bayan countdown. Each face uses its recommended palette.

Classic sheets are earlier references and were excluded from the latest review. Horizon Mobile is shown separately in portrait. Screenshots use fixed preview times and sample weather.

## Regenerate the TV galleries

Connect an Android device or emulator, then run from the repository root with JDK 17 available:

```bash
FACE_GALLERY_FACES=horizon,ufuq,safaa,noor,sahar,kaash,mihrab \
  ./scripts/generate_face_gallery.sh
```

ImageMagick is required. The script builds and installs the debug preview, captures the scenes, and writes the sheets to `docs/face-gallery`. Use `FACE_GALLERY_LANGUAGES=en,ta,si` to select languages or `FACE_GALLERY_THEMES` to select alternate palettes. Include `classic` in `FACE_GALLERY_FACES` when refreshing its reference sheets.

The page uses Markdown headings and links with simple HTML image and disclosure tags. No scripts or custom CSS are needed. Renderers that disable HTML can still use the [image files](face-gallery/) directly.
