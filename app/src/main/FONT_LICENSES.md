# Bundled fonts

All fonts in `res/font/` are Google-hosted variable fonts distributed under the
[SIL Open Font License 1.1](https://openfontlicense.org/), sourced from
https://github.com/google/fonts:

- `archivo_variable.ttf` — Archivo (`ofl/archivo`)
- `noto_sans_tamil_variable.ttf` — Noto Sans Tamil (`ofl/notosanstamil`)
- `noto_sans_sinhala_variable.ttf` — Noto Sans Sinhala (`ofl/notosanssinhala`)
- `noto_naskh_arabic_variable.ttf` — Noto Naskh Arabic (`ofl/notonaskharabic`)

Each family's own `OFL.txt` is available in its source directory above.
